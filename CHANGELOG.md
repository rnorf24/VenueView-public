# Changelog

## 1.0.0-rc.3 — public portfolio candidate

- Created a fresh, history-free public source tree from the `1.0.0-rc.2` code
  line.
- Replaced organization-derived venues, profiles, rules, events, and expected
  outputs with fictional demonstration material.
- Generalized calendar-provider language in code, tests, and interface copy.
- Added a public project narrative, explicit limitations, privacy guidance,
  publication checks, and portfolio wording.
- Added carefully qualified ORDA, Lake Placid Conference Center, and Olympic
  Center context to the narrative while keeping executable configuration and
  demonstrations fictional.
- Preserved the processing engine, local interface, exporters, packaging
  definitions, and synthetic test coverage.

Private development milestones are intentionally not reproduced in this
repository because their history and configuration were not part of the public
sanitization boundary.
